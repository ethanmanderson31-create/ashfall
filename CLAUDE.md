# Ashfall — project rules for Claude

Third-person roguelike shooter, Godot 4.7, GDScript. Everything is built in code (`main.tscn` holds only a script).

**Start of every session:** read `docs/sessions/PLAYBOOK.md` (how the user works + taste) and the newest `docs/sessions/session-NN/SUMMARY.md` (where we left off). Don't read older sessions unless needed.
**End of session:** the user types `/close-session` → follow `.claude/skills/close-session/SKILL.md`.

## Run / verify
- Godot: `~/Applications/Godot.app/Contents/MacOS/Godot --path .`
- Screenshot tour: `... -- --shots` → `screenshots/` (look at the PNGs, don't guess)
- Benchmark: `... -- --bench` · creature turntable: `-- --creatures` · swim tour (lakes/islands, crawl GIF dump): `-- --shots --swim`
- Ship: `bash tools/export_mac.sh`, then `rm -rf ~/Desktop/Ashfall.app && cp -R build/Ashfall.app ~/Desktop/`
- After any gameplay change: run `--shots`, check for `SCRIPT ERROR`, then export to Desktop.

## Layout
- `scripts/core` (main, game, settings, audio autoloads) · `player` · `enemies` · `combat` · `ui` · `world` · `pickups`
- `shaders/` · `assets/audio/` · `tools/` (python helpers) · `docs/`

## Code rules
- GDScript: give explicit types when the value comes from a Dictionary/Variant (`var x: float = d["k"]`), or it won't compile.
- Sound catalog in `audio.gd` is generated by `tools/build_sound_catalog.py` — edit SLOTS there, never by hand.
- Synth sounds: `python3 -I tools/sfx_synth.py assets/audio/synth <names>` (water/ambience/world sounds live in `tools/sfx_world.py`, registered into it). In zsh pass a name list with `${=NAMES}`.
- New `class_name` scripts need `Godot --headless --path . --import` once before they resolve.
- Only CC0 assets. Record sources in `assets/audio/CREDITS.md`.
- Keep files focused; don't grow `player.gd` / `hud.gd` further — add a new script.
- Delete replaced/unchosen assets and code; no dead options left behind.

## Working with me (the user)
- Show real in-engine screenshots/GIFs for visual choices — never flat mockups.
- For look/feel decisions, give 2–4 options and let me pick before building.
- Taste notes: realistic molten-rock style; fantasy/whimsical UI sounds (no bells, no harsh crunch on cards); monsters quiet at range and silent when dead.
- Ask before big refactors; small fixes just do.
